# 🌟 Яна | Твой мир на английском
### Интерактивные развивающие английские сканворды

Интерактивное образовательное веб-приложение для увлекательного изучения английского языка через классические иллюстрированные сканворды. Обогащайте словарный запас, запоминайте правильное написание, слушайте эталонное произношение и практикуйте слова в контексте предложений.

---

## 🚀 Ключевые возможности

- 🧩 **Классические сканворды (Scanwords)**:
  - Определения, перевод и ассоциативные эмодзи расположены прямо внутри ячеек сетки.
  - Направляющие стрелки указывают направление слова: вправо (→) или вниз (↓).
  - Поддержка сдвоенных ячеек-подсказок (одна ячейка задаёт два разных слова).
  - Плотное заполнение поля (90–94% площади), отсутствие пустых зон и декоративные тематические виньетки (`🐾`, `🍓`, `🏡`, `🏆`, `✏️`, `✈️`).

- 🗣️ **Живая озвучка слов (Text-to-Speech)**:
  - Автоматическое произношение отгаданного английского слова с помощью Web Speech API.
  - Кнопка повторного прослушивания на карточке подсказки и в словаре.

- 📖 **Тематический иллюстрированный словарь**:
  - Полный справочник всех слов курса с русским переводом, международной транскрипцией (IPA), эмодзи и примерами предложений.
  - Быстрый поиск по английским и русским словам.
  - Фильтрация по разделам и интерактивная карточка каждого слова.

- 🎯 **6 тематических категорий (12 сканвордов)**:
  1. **Животные (Animals)** — *Старт (5×5)* и *Мастер (6×6)*
  2. **Еда и напитки (Food & Drinks)** — *Старт (5×5)* и *Мастер (6×6)*
  3. **Семья и дом (Family & Home)** — *Старт (5×5)* и *Мастер (6×6)*
  4. **Спорт и игры (Sports & Games)** — *Старт (5×5)* и *Мастер (6×6)*
  5. **Школа и уроки (School & Study)** — *Старт (5×5)* и *Мастер (6×6)*
  6. **Путешествия и город (Travel & City)** — *Старт (5×5)* и *Мастер (6×6)*

- 📱 **Адаптивное управление**:
  - Ввод с физической клавиатуры (буквы A–Z, Backspace, стрелки).
  - Специально оптимизированная сенсорная виртуальная клавиатура для мобильных устройств.
  - Быстрая навигация между ячейками и автоматический переход к следующей букве.

- 💡 **Система помощи и подсказок**:
  - Открытие текущей буквы при затруднении.
  - Подсветка ошибок (проверка введённых букв).
  - Оценка прохождения от 1 до 3 звёзд в зависимости от количества использованных подсказок.

- 🔍 **Масштабирование сетки**:
  - Регулировка масштаба ячеек (Обычный, Крупный, Огромный) для удобного чтения на смартфонах, планшетах и мониторах.

- 💾 **Сохранение прогресса**:
  - Полное автосохранение прогресса каждого сканворда, отгаданных слов, полученных звёзд и общей статистики решённых головоломок в `localStorage`.

## 🛠 Стек технологий

- **Фреймворк**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Сборщик**: [Vite 6](https://vitejs.dev/)
- **Стилизация**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Иконки**: [Lucide React](https://lucide.dev/)
- **Анимации & Эффекты**: [Motion](https://motion.dev/) и [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Аудио**: Web Audio API (синтез ретро-звуков) и Web Speech Synthesis API (озвучка слов)

## 💻 Установка и локальный запуск

### Требования
- Node.js 18+
- npm 9+

### Шаги установки

1. Клонируйте репозиторий или скачайте архив проекта.
2. Перейдите в корневую папку:
   ```bash
   cd project
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
5. Откройте в браузере:
   ```text
   http://localhost:3000
   ```

### Скрипты сборки и проверки

- `npm run dev` — запуск dev-сервера с hot-reload.
- `npm run build` — компиляция проекта для продакшена в директорию `dist/`.
- `npm run preview` — предпросмотр продакшен-сборки.
- `npm run lint` — проверка типов с помощью TypeScript компилятора (`tsc --noEmit`).
